# Stationery Shop Cart

A responsive shopping cart built with HTML, CSS, and JavaScript.

## Features

- Add or decrease item quantities
- Prevent quantities from going below 1
- Remove items from the cart
- Automatic subtotal and 10% discount for orders of Rs. 1000 or more
- Empty-cart message

## Run

Open `index.html` directly in a browser, or serve the folder with:

```powershell
python -m http.server 5500
```

Then visit `http://localhost:5500`.
